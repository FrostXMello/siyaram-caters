# Siyaram Caters

Concept homepage for Siyaram Caters, Jaipur — sweets, wedding feasts and catering, art-directed around the colour and architecture of the Pink City.

This is a client demo. The opening screen is the immersive hero. Story, mithai, feasts, gatherings and Jaipur are a designed index that opens the catering enquiry.

```bash
npm install
npm run dev
```
