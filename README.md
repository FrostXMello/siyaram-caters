# Siyaram Caters

Concept website for Siyaram Caters, Jaipur — catering, sweets, restaurant and venues, art-directed around the colour and hospitality of the Pink City.

This is a client demo. Content is drawn from [siyaramcaters.com](https://siyaramcaters.com/).

```bash
npm install
npm run dev
```

Live: https://siyaram-caters.vercel.app
